# JOY N COLLECTIVE — Complete E-Commerce Starter

## Included now
- Branded homepage and shop
- 12 temporary professional product images
- Search and category filtering
- Individual product pages
- Quantity selector
- Working cart
- Checkout form
- Cash on Delivery / GCash-manual / Bank Transfer order options
- Local customer account demo
- Order history
- Admin dashboard
- Inventory view and sales/order summary
- Responsive design

## Important production note
This package is complete as a deployable starter, but its customer accounts, orders, cart persistence, and admin password are browser-local demo storage so it works immediately without credentials. For a real public production store where orders persist across devices and multiple customers, connect Supabase (database/auth/storage) and a payment gateway. The included `.env.example` is ready for those credentials.
